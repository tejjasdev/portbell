# Roadmap

Plans can change; this is the current intention. Each version has one theme.

| Version | Theme | Highlights |
| --- | --- | --- |
| **v0.1** | Usable core | Request list and detail, reply editor, delay, flags and config file, CORS switch, headless JSON lines, copy as curl, save request, safe defaults, binaries for Windows, macOS and Linux |
| **v0.2** | Reusable | Save and load named replies, install script, Homebrew tap and Scoop bucket, Docker image, more recipes |
| **v0.3** | Comfortable | Search and filter requests, failure presets (connection reset, timeout), HTTPS with a generated certificate, custom key bindings, light and dark themes, winget, deb and rpm packages |
| **v1.0** | Stable | Flags, config keys and JSON-line fields frozen under the compatibility promise |

**Later, only if users ask:** different replies per path and method, history across runs, HAR
export, WebSocket viewing.

**Will not build:** an API client, a tunnel or proxy, accounts or cloud features, telemetry.

Want something from this list, or something not on it? [Open an issue](https://github.com/tejjasdev/portbell/issues/new/choose).
