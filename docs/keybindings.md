# Keybindings

## Main screen

| Key | Action |
| --- | --- |
| `Tab` | Switch between the request list and the detail pane |
| `↑` `↓` or `k` `j` | Move in the list, or scroll the detail pane |
| `PgUp` `PgDn` | Move one page |
| `g` / `Home`, `G` / `End` | Jump to the first or last item |
| `e` | Edit the reply |
| `c` | Copy the selected request as a curl command |
| `s` | Save the selected request to `./portbell-saved` |
| `?` | Show help |
| `q` or `Ctrl+C` | Quit |

## Reply editor

| Key | Action |
| --- | --- |
| `Ctrl+S` | Apply the reply |
| `Esc` | Cancel |
| `Tab` | Switch between the text and the delay field |
| `Enter` (in the delay field) | Apply |

Custom keybindings are planned for v0.3.

The mouse is not captured, so you can select and copy text with it as in any terminal.
If your terminal turns the wheel into arrow keys in full-screen programs, the wheel scrolls too.
