# 0001: Write it in Go

**Status:** Accepted

**Context.** We need a small tool that runs on Windows, macOS and Linux with nothing to install first,
contains an HTTP server, and is easy for newcomers to contribute to. The tool this project follows
(httplab) is written in Go.

**Decision.** Use Go. The standard library has a production-quality HTTP server, programs compile to one
static binary, and cross-compiling is a single environment variable.

**Consequences.** Contributors need Go. Binaries are a few megabytes. Rust (with ratatui) would give smaller
binaries but a steeper start for contributors and slower builds; we are not choosing it now.
